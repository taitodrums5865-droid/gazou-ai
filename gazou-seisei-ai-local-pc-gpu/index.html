画像生成AIをローカルで動かすときに大事なのは、GPUのVRAM(ビデオメモリ)の量です。公式の数字では、Stable Diffusion 3.5 Mediumは9.9GB、FLUX.2 [klein] 4Bはおよそ13GBのVRAMを使います。これから買うなら、VRAM 16GBのGPUを選ぶと、多くのモデルを無理なく動かせます。GPUが無いPCやMacなら、無料のツールのComfyUIを手持ちの環境で試すか、クラウドの無料枠から始めましょう。

ローカルとクラウドは何が違う?

ローカルは「最初にGPU代がかかり、あとは電気代だけで回数の制限がない」形です。クラウドは「最初の費用はかからず、使った分か月額を払う」形。違いは次の表のとおりです。

ローカルとクラウドは何が違う?
比べる点ローカル(自分のPC)クラウド(例: Comfy Cloud)
最初の費用GPU・PCの購入代0円から(無料枠あり)
毎月の費用電気代Standardで月$20から(料金・2026年10月時点・最新は公式で確認)

手間導入・更新・トラブル対応を自分でほぼ不要

ローカルを選ぶ人がよく挙げる理由は、回数を気にせず何百枚も試せることと、作った画像や下絵が外に出ないことです。

ただし、モデルを自由に入れられることと、作った画像を自由に使えることは別の話です。たとえばStable Diffusion 3.5は「Stability AI Community License」で、年間の売上が100万ドル未満の個人・組織なら無料で商用利用できます(Stability AI)。モデルごとにライセンスが違うので、副業や仕事で使う前に画像生成AI商用利用、規約のどこを確認するかで確認する所を見ておくと安心です。

必要なVRAMはモデルでどれくらい違う?

目安は、古いモデルなら8GB、2024年以降の新しいモデルなら12〜16GBです。各社が公開している数字を並べると、次のようになります。

必要なVRAMはモデルでどれくらい違う?
モデル公式の数字出典
Stable Diffusion 1.5 / SDXL(AUTOMATIC1111で使う場合)4GBのGPUに対応(2GBで動いた報告もあり)AUTOMATIC1111 GitHub
Stable Diffusion 3.5 Medium(25億パラメータ)9.9GB(テキストエンコーダーは別)Stability AI
FLUX.2 [klein] 4B約13GB。RTX 3090 / 4070以上Hugging Face
FLUX.1 Kontext [dev]元は24GB → FP8で12GB(RTX 40シリーズ)、FP4で7GB(RTX 50シリーズ)NVIDIA

Stability AIは、Mediumについて次のように書いています。

「This model only requires 9.9 GB of VRAM (excluding text encoders) to unlock its full performance」(Stability AI)

訳すと「このモデルの性能を出し切るのに必要なVRAMは9.9GBだけ(テキストエンコーダーを除く)」です。気をつけたいのは「テキストエンコーダーを除く」の部分。プロンプトを読み取る部品の分は、この数字に入っていません。8GBのGPUでぎりぎり動くかどうかではなく、少し余裕を持たせたほうがいいのはこのためです。

FLUX.2 [klein] 4BのHugging Faceのページには、次の一文があります。

「The FLUX.2 [klein] 4B model fits in ~13GB VRAM and is accessible on NVIDIA RTX 3090/4070 and above.」(Hugging Face)

訳すと「FLUX.2 [klein] 4Bは約13GBのVRAMに収まり、NVIDIA RTX 3090 / 4070以上で使える」。ライセンスはApache 2.0です(Hugging Face)。

VRAMが少なくても動くことはある

ComfyUIのGitHubには、「4GBのVRAMと8GBのRAMでも、いちばん大きいオープンソースのモデルを比較的速く動かせる」とあります(ComfyUI GitHub)。足りない分をメインメモリに逃がす仕組みがあるからです。

ただ、これは「動く」という意味です。待ち時間は長くなります。毎日何十枚も作るなら、VRAMはモデルの公式の数字より多めにしておきましょう。

対応しているGPUの種類

ComfyUIの公式の動作環境ページに載っているGPUの種類は8つです(NVIDIA、AMD(Linux)、AMD(Windows)、Intel Arc、Apple Silicon、Ascend NPU、Cambricon MLU、Iluvatar Corex)。GPUが無くても--cpuで動かせます(ComfyUI 動作環境・2026-10-19にこのサイトで数えた)。

とはいえ、手順の解説や配布されているモデルの多くはNVIDIAのGPUを前提にしています。AMDやIntelは安く買えることもありますが、つまずいたときに解決方法を見つけにくいのが難点です。

同じRTX 5060 Ti 16GBでも、発売時とくらべて4万円以上高くなりました。8GB版はもっと安く売られています。それでも上のVRAMの表を見ると、8GBで余裕を持って動くのは古いモデルまで。あとからGPUを買い直すより、最初に16GBを選んだほうが結果的に安く済むことが多いでしょう。

クラウドと比べると何か月分?

たとえば、RTX 5060 Ti 16GBの12万9,800円を、Comfy Cloud Standardの月$20と比べてみます。1ドル150円で計算すると月3,000円なので、約43か月分です(為替は仮の数字です)。

判断の目安は次の2つです。

  • 3年以上、ほぼ毎日使うつもり → ローカルのほうが割安になりやすい
  • 週に数回・月に数十枚ほど → クラウドのほうが割安で手間も少ない

GPUを積んだPCを持っていない人は、GPUのほかに電源やケースの費用もかかることを入れて考えてください。

ComfyUI Desktopを入れる手順(Windows)

Windowsで一番手間が少ないのは、ComfyUI Desktop(公式のインストーラー版)です。公式の動作環境は、Windows 10以降で、空き容量は1回のインストールにつき4.85GB以上がおすすめとされています(Comfy Desktop for Windows)。モデルのファイルは別に何GBもあるので、SSDを数十GB空けておきましょう。

  1. 公式サイト(comfy.org)からWindows用のインストーラー(.exe)をダウンロードして実行し、表示に沿って進めます。
  2. スタートメニューかデスクトップのショートカットから「Comfy Desktop」を起動します。
  3. 「How do you want to run Comfy?」と出たら、「Local」を選びます(「Cloud」はComfy CloudのGPUで動かす方です)。
  4. 「I agree to the EULA and Terms of Service」にチェックを入れます。ここだけは必須です。利用データの送信とベータ機能のチェックは、入れなくても進めます。
  5. 迷ったら「Express Install with recommended settings」にチェックを入れます。おすすめの設定で入ります。
  6. 「Continue」を押します。「Preparing your install…」と出たら、終わるまで待ちましょう。

初回起動の画面の流れはComfy Desktop 概要にまとまっています。入ったら、最初はテンプレートのワークフローで1枚作ってみてください。プロンプトの組み立て方は画像生成AIプロンプトの書き方、順番で決まるで順番に書いています。

つまずきやすい所と直し方

どちらのカードも選ばれていない:GPUの性能が足りないと判断されると、「Local」と「Cloud」のどちらも最初から選ばれていない状態になります。画面に出ている認識されたハードウェアを見て、GPUの名前が正しいか確かめましょう。「Cloud」に「Recommended for your hardware」と出ていたら、そのPCではクラウドのほうが向いている、という意味です(Comfy Desktop 概要)。

起動しない・途中で止まる:ログの%APPDATA%\Comfy Desktop\logsの中のapp.logを開いて、最後のほうのエラーの文をそのまま検索します(Comfy Desktop for Windows)。

入れたモデルがどこにあるか分からない:モデルは%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared(古い版では%USERPROFILE%\ComfyUI-Shared)にまとめて置かれます(Comfy Desktop for Windows)。

AUTOMATIC1111でPythonのエラーが出る:AUTOMATIC1111はPython 3.10.6を指定していて、「新しいバージョンのPythonはtorchに対応していない」と書かれています(AUTOMATIC1111 GitHub)。ComfyUIを手作業で入れる場合は、反対にPython 3.13がおすすめです(ComfyUI 動作環境)。ツールによって合うPythonが違う、と覚えておけば、エラーの原因に早く気づけます。

画面の表示が崩れる:ComfyUIはGoogle Chromeの143以降をすすめています(ComfyUI 動作環境)。

よくある質問

GPUが無いノートPCでも画像生成AIをローカルで動かせますか?

動かせます。ComfyUIは--cpuで、GPUが無くても動きます(ComfyUI 動作環境)。ただ1枚に時間がかかるので、普段使うならクラウドの無料枠から試すほうが現実的です。

VRAM 8GBのGPUではもう足りませんか?

SD1.5やSDXLなら、8GBでも十分に使えます。SD3.5 Mediumは公式で9.9GB(テキストエンコーダーを除く)なので、8GBでは設定の工夫が必要です(Stability AI)。新しいモデルを中心に使うなら、16GBが目安です。

Macでもローカルで動きますか?

M1以降のApple Silicon Macなら、ComfyUIが公式に対応しています(ComfyUI 動作環境)。ただ、解説記事や配布されているモデルはNVIDIAのGPU向けが多く、設定を自分で調べる場面が増えます。

ローカルで作った画像は商用利用できますか?

使ったモデルのライセンスで決まります。Stable Diffusion 3.5は年間売上100万ドル未満なら無料で商用利用でき(Stability AI)、FLUX.2 [klein] 4BはApache 2.0です(Hugging Face)。確認のしかたは規約のどこを確認するかにまとめています。
