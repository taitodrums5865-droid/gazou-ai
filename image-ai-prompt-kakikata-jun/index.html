画像生成AIプロンプトの書き方、順番で決まる

公開 2026-10-15 · 19分で読めます

#画像生成AI #プロンプト #ChatGPT #Gemini

画像生成AIのプロンプトは、「主語(何を)→構図(どう写すか)→画風(どんな見た目か)」の順番で書くと、思ったとおりの絵になりやすくなります。Google の公式ガイドも「主語＋動作＋場所＋構図＋スタイル」という型を紹介しています(Google)。単語を増やす前に、まず順番をそろえてください。順番が毎回同じだと書き忘れが減り、結果を見比べて直すのも楽になります。

この記事の要点

  • プロンプトは主語→構図→画風の順番で書くと結果が安定する
  • 1回の修正で変える点は1か所だけにすると効果を比較しやすい
  • 否定形ではなく欲しい状態を肯定形で書くと意図通りになりやすい

なぜ「順番」で結果が安定するのか

順番を決めると、①書き忘れがなくなり、②1か所だけ変えて結果を比べられるようになります。安定する理由はこの2つです。主なサービスの公式ガイドも、書く要素を順番つきで紹介しています。

なぜ「順番」で結果が安定するのか
サービス公式ガイドが示す要素の並び出典
Google(Gemini)主語＋動作＋場所・状況＋構図＋スタイルGoogle Pics のヘルプ
Adobe Firefly主語、その特徴、スタイル・表現方法。Adobe の案内では「主語→質感・細部→背景→光→構図と余白」の順も紹介Adobe ヘルプ
OpenAI(ChatGPT・API)複雑な依頼は「場面→主語→細部→制約」の順に区切って書くOpenAI 画像プロンプトガイド
Midjourney何を入れたいかを具体的に書き、入れたくない物は書かないMidjourney Prompt Basics

表のとおり、細かい並びはサービスによって少しずつ違います。OpenAI は場面を先に書く順番を勧めています。それでも、どのガイドも「主語」「見せ方」「見た目のスタイル」を分けて書く点は同じです。そこでこの記事では、覚えやすい「主語→構図→画風」を基本の型にします。

もう1つの理由は、直し方がはっきりすることです。OpenAI のガイドは「1回の修正で変えるのは1か所だけ」と勧めています(OpenAI)。順番が決まっていれば「2番目の構図だけ変える」といった直し方ができるので、何が効いたのかが分かります。

基本の型「主語→構図→画風」の書き方

型は「【主語】、【構図】、【画風】」の3つです。1つにつき1〜2文で足ります。OpenAI も「多くの場合、はっきりした1〜3文で十分」としています(OpenAI Academy)。

① 主語:何が・何をしているか

最初に「誰が・何が」「何をしているか」「どこで」を書きます。Google のヘルプでは、「猫」だけよりも「日の当たる窓辺で丸くなって眠る、ふわふわの茶トラ猫」のように具体的に書くほうがよいと説明されています(Google Pics のヘルプ)。

  • 弱い例:女の子
  • 強い例:黄色いレインコートを着た小学生の女の子が、水たまりを跳び越えている

判断の基準:この文だけ読んで、ほかの人が同じ物を思い浮かべられるか。

② 構図:どう写すか

次に、カメラの位置と画面の中での配置を書きます。Google のガイドが挙げる例は「アップ」「引き(ワイドショット)」「ローアングル」「ポートレート」です(Google)。

  • 近さ:顔のアップ / 上半身 / 全身 / 引きの風景
  • 角度:正面 / 斜め上から / 下から見上げる / 真上から
  • 配置:人物は右側、左側に文字を入れる余白

判断の基準:使う場所(SNS・ブログのアイキャッチ・資料)に合わせて、余白や縦横の向きを決めておく。

③ 画風:どんな見た目か

最後に、表現の種類・光・色を書きます。Google のガイドの例は「3Dアニメーション」「フィルムノワール」「水彩画」「写実的な写真」などです(Google)。Gemini のヘルプも「写実的、木炭画」のようにスタイルを書くよう案内しています(Gemini アプリ ヘルプ)。

  • 表現:写真風 / 水彩 / フラットなイラスト / 3D / 手描き風
  • 光:やわらかい自然光 / 夕方の逆光 / スタジオ照明
  • 色:パステル調 / 落ち着いた青系 / コントラスト強め

3つを並べた例

たとえば、ブログのアイキャッチなら次のように書きます。

黄色いレインコートを着た小学生の女の子が、雨上がりの公園で水たまりを跳び越えている。横長の構図で、女の子は右側の全身、左側に文字を入れる余白を広くとる。やわらかい水彩画風で、雨上がりの明るい光、パステル調の色。

用途別のテンプレートと、順番を入れ替えるときのコツ

型は同じでも、用途に合わせて「構図」の書き方を変えると使える画像になります。そのまま書き写して、【 】の中だけ入れ替えて使ってください。

用途別のテンプレートと、順番を入れ替えるときのコツ
用途主語構図画風
SNS投稿【季節の和菓子】がお皿にのっている正方形、真上から、中央に1つ明るい自然光の写真風
ブログのアイキャッチ【パソコンに向かう人】横長、人物は右寄せ、左に余白フラットなイラスト、2〜3色
資料・スライド【成長を表す芽と階段】横長、白い背景、中央に小さめシンプルなアイコン風、青系
趣味のイラスト【銀髪の旅人が古い地図を広げている】上半身、少し見下ろす角度油絵風、夕方の暖かい光
副業の素材づくり【観葉植物のある机】横長、手前をぼかす、文字なし写真風、やわらかい光

順番を入れ替えてよいとき

背景や場の雰囲気が主役の画像(街並み、店内、風景など)は、OpenAI のガイドのように「場面」から書き始めても構いません(OpenAI)。大事なのは、一度決めた順番をそのシリーズの間は変えないことです。順番をそろえておけば、何枚か作ったあとに「構図の文だけが違う」と見比べられます。

文字を入れたいとき

画像の中に文字を入れたいときは、入れる文字をかぎかっこや引用符で囲み、置く場所と書体の雰囲気も書きます。これは OpenAI と Google の両方のガイドが勧めている方法です(OpenAI、Google Pics のヘルプ)。ただし、Google は文字の描写をまだ苦手な点として挙げています(Google)。日本語の文字は崩れることがあるので、生成後に必ず読み直し、大事な文字は画像編集ソフトであとから入れるほうが確実です。

手順:ChatGPT と Gemini で型を使う

どちらのサービスも、画像のメニューを開いて型どおりの文を送るだけで使えます。画面の名前は、2026年10月時点の公式ヘルプなどに出てくる表記です。表示はアップデートで変わることがあります。

ChatGPT の場合

  1. chatgpt.com を開いてログインします。
  2. 入力欄の「＋」を押し、「画像を作成する」を選びます(サイドバーの「画像」からも開けます)(東京経済大学の利用ガイド)。
  3. 「主語→構図→画風」の順に書いた文を入力して送信します。
  4. 直したいときは、「構図だけ変えて。人物を左に寄せて、それ以外は同じ」のように、変える所と残す所を両方書きます。OpenAI のガイドも、変更点と残したい点を分けて書くよう勧めています(OpenAI)。

Gemini の場合

  1. gemini.google.com を開きます。
  2. 「サイドバーを開く」→「画像」を選びます(Gemini アプリ ヘルプ)。
  3. テンプレートを選ぶか、型どおりの文を入力します。ヘルプでは、文の最後に「描いて」「生成して」「作成して」を付けるよう案内しています。
  4. 「送信」を押します。

画像の生成は13歳以上、画像の編集は18歳以上が条件です(Gemini アプリ ヘルプ)。

つまずきやすい所と直し方

うまくいかないときの原因は、だいたい「書いていない」「否定形で書いた」「一度に変えすぎた」のどれかです。

つまずきやすい所と直し方
よくある失敗原因直し方
入れたくない物が出てくる「ケーキなし」のように否定形で書いた欲しい状態を書く。Midjourney は「no cake」と書くとケーキが出ることがあると説明しています(Midjourney)。Google も「車なし」ではなく「人も車もいない静かな通り」と書くよう勧めています(Google)
思っていない物が勝手に足される説明が足りず、AIが補った主語・構図・画風のうち、書いていない部分を足す。ChatGPT は説明が少ないと細部を補うことがあると OpenAI が説明しています(OpenAI Academy)
直すたびに全体が変わる一度に何か所も変えた1回の修正で変えるのは1か所だけ。残したい点も書き直す(OpenAI)
何度直しても近づかない会話が長くなり、前の指示が混ざったChatGPT に「この画像に使ったプロンプトを見せて」と頼み、ずれている所を確認してから新しいチャットでやり直す(OpenAI Academy)
「大きい」「きれい」が効かないことばがあいまい「巨大な」「見上げるほどの」など、もっと具体的なことばにする(Midjourney)
画像が作れなくなったその日の上限に達した時間をおくか、有料プランを検討する(次の章)

次にやること

まずは無料版で、型どおりのプロンプトを1つ作ることから始めてください。

① 自分でやる人の今日の一歩

  1. 作りたい画像を1つ決め、「主語」「構図」「画風」を1文ずつメモに書く(上の用途別テンプレートを写してOK)。
  2. ChatGPT か Gemini の無料版で送り、気になった所を1か所だけ直してもう一度作る。
  3. うまくいったプロンプトはメモ帳などに保存し、次から【 】の部分だけ入れ替えて使う。

② 自分でやるのが大変・早く確実にしたい人向け

  • 公式の無料ガイドで学ぶ(0円):OpenAI Academy の画像生成ページや、Google の Gemini 画像生成のコツは無料で読めます。向いているのは自分のペースで学びたい人。英語のページもあるので、英語が苦手な人には少し読みにくいです。
  • 有料プランにする(月725円〜):Google AI Plus は月725円、Firefly Standard は月1,580円(2026年10月時点・最新は公式で確認)。向いているのは、無料版の上限に週に何度も引っかかる人です。月に数枚しか作らない人は、無料版のままで十分なことが多いです。
  • 仕事用ならチームで使えるプランや販売店に相談する:会社の資料や広告に使う場合は、Adobe や OpenAI の法人向けプランの問い合わせ窓口に相談する方法もあります。個人で趣味として使う人には向いていません。

どれも、急いで選ぶ必要はありません。まず無料版で型が合うかどうかを確かめてから決めてください。

よくある質問

プロンプトは日本語と英語、どちらで書くべきですか?

ChatGPT と Gemini は日本語の文章で頼めるので、まずは日本語で問題ありません。Gemini のヘルプも、日本語で「描いて」「生成して」と書く例を載せています。Midjourney は英語の説明が中心なので、英語で書くほうが扱いやすい場合があります。

プロンプトは長いほうがいいですか?

長ければよいわけではありません。OpenAI は「多くの場合、はっきりした1〜3文で十分」としています。主語・構図・画風の3つが入っていれば、短くても十分です。

「〇〇を入れないで」と書いても出てくるのはなぜですか?

否定形で書くと、その単語自体が手がかりになり、かえって描かれることがあるためです。Midjourney と Google の公式ガイドも、欲しい状態を肯定形で書くよう勧めています。たとえば「人なし」ではなく「誰もいない静かな通り」と書きます。

同じキャラクターを何枚も描かせるにはどうすればいいですか?

最初のプロンプトで見た目(髪型・服・色)をくわしく決め、次からは「同じキャラクターで、場面だけ変えて」と頼みます。Google のガイドもこのやり方を紹介しています。毎回、主語の文をそのまま書き写して使うと、見た目がずれにくくなります。

作った画像はブログや仕事に使ってもいいですか?

サービスやプランによって条件が違うので、使う前に各サービスの規約を確認してください。確認する場所は画像生成AI商用利用、規約のどこを確認するかにまとめています。
